
# Flutter Icon Widgets

A simple Flutter application demonstrating how icon widgets are used to display symbols and create interactive elements in a mobile application.

## Overview

This project was developed as part of a Mobile Application Development class activity to explore Flutter's Icon and IconButton widgets.

The application demonstrates how icons can be customised and made interactive through user input.

## Features

- Displays a Flutter icon using the Icon widget.
- Uses an IconButton for notifications.
- Includes an interactive favourite button.
- Demonstrates changing icon colours and appearances.
- Uses setState() to update the UI when the favourite button is tapped.

## Widgets Used

- **Icon:** Displays a graphical symbol.
- **IconButton:** Creates an interactive icon.
- **Scaffold:** Provides the basic screen structure.
- **AppBar:** Displays the application title and notification button.
- **Column:** Arranges widgets vertically.
- **Center:** Positions widgets in the centre of the screen.
- **SizedBox:** Adds spacing between elements.
- **Text:** Displays text on the screen.

## Getting Started

### Prerequisites

- Flutter SDK
- Android Studio or Visual Studio Code
- An Android emulator or physical device

### Running the Application

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <project-folder>
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
